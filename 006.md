# 1. Class-Based Objects

## Definition

A **class** is a blueprint for creating objects.

Think of it like this:

```text
Blueprint (Class)
        ↓
House 1 (Object)
House 2 (Object)
House 3 (Object)
```

The blueprint defines what every house has.

Similarly,

```text
Class
   ↓
Object 1
Object 2
Object 3
```

---

## Syntax

```javascript
class Person {

}
```

---

## Creating an Object

```javascript
class Person {

}

const p1 = new Person();
```

Here

```javascript
Person
```

is the class.

```javascript
p1
```

is the object.

---

## Constructor

The constructor runs automatically whenever an object is created.

```javascript
class Person {

    constructor(name, age) {

        this.name = name;
        this.age = age;

    }

}

const p1 = new Person("John", 22);

console.log(p1);
```

### Output

```text
Person {
    name: "John",
    age: 22
}
```

---

## Methods

Methods are functions inside classes.

```javascript
class Person {

    constructor(name, age) {

        this.name = name;
        this.age = age;

    }

    greet() {

        console.log("Hello");

    }

}

const p1 = new Person("John", 22);

p1.greet();
```

### Output

```text
Hello
```

---

## Another Example

```javascript
class Student {

    constructor(name, grade) {

        this.name = name;
        this.grade = grade;

    }

    study() {

        console.log(this.name + " is studying.");

    }

}

const s1 = new Student("Ali", "A");

s1.study();
```

Output

```text
Ali is studying.
```

# 2. Array Destructuring

## Definition

Array destructuring allows you to extract values from an array into variables.

---

Without destructuring

```javascript
const numbers = [10,20,30];

const a = numbers[0];
const b = numbers[1];
const c = numbers[2];

console.log(a,b,c);
```

Output

```text
10 20 30
```

---

With destructuring

```javascript
const numbers = [10,20,30];

const [a,b,c] = numbers;

console.log(a,b,c);
```

Output

```text
10 20 30
```

Much shorter.

---

## Skipping Values

```javascript
const numbers = [10,20,30];

const [a,,c] = numbers;

console.log(a,c);
```

Output

```text
10 30
```

---

## Rest Operator

```javascript
const numbers = [10,20,30,40,50];

const [a,b,...rest] = numbers;

console.log(rest);
```

Output

```text
[30,40,50]
```

---

# 3. Object Destructuring

Objects are destructured using property names.

---

Without destructuring

```javascript
const person = {

    name:"John",
    age:25

};

console.log(person.name);
console.log(person.age);
```

---

With destructuring

```javascript
const person = {

    name:"John",
    age:25

};

const {name,age} = person;

console.log(name);
console.log(age);
```

Output

```text
John
25
```

---

## Renaming Variables

```javascript
const person = {

    name:"John",
    age:25

};

const {name:firstName} = person;

console.log(firstName);
```

Output

```text
John
```

---

## Default Values

```javascript
const person = {

    name:"John"

};

const {name,age=18} = person;

console.log(age);
```

Output

```text
18
```

---

# Array vs Object Destructuring

| Array         | Object             |
| ------------- | ------------------ |
| Uses position | Uses property name |
| `[a,b]`       | `{name,age}`       |

# 4. Class-Based Components (React)

Before React Hooks, components were written as classes.

Example

```jsx
import React, { Component } from "react";

class App extends Component {

    render() {

        return (

            <h1>Hello React</h1>

        );

    }

}

export default App;
```

---

## Functional Component

Modern React

```jsx
function App() {

    return (

        <h1>Hello</h1>

    );

}
```

React now recommends functional components with Hooks for new projects.

---

## State in Class Components

```jsx
class Counter extends React.Component {

    constructor() {

        super();

        this.state = {

            count:0

        };

    }

    render() {

        return (

            <h1>{this.state.count}</h1>

        );

    }

}
```

# 5. Inheritance

## Definition

Inheritance allows one class to use the properties and methods of another class.

Real-life example:

```text
Animal

↓

Dog
```

Dog is an Animal.

Dog inherits Animal's behavior.

---

Example

```javascript
class Animal {

    eat() {

        console.log("Eating");

    }

}

class Dog extends Animal {

}

const d = new Dog();

d.eat();
```

Output

```text
Eating
```

The `Dog` class inherited the `eat()` method.

---

# 6. extends

The keyword

```javascript
extends
```

creates inheritance.

Syntax

```javascript
class Child extends Parent {

}
```

Example

```javascript
class Animal {

    sleep() {

        console.log("Sleeping");

    }

}

class Cat extends Animal {

}

const c = new Cat();

c.sleep();
```

Output

```text
Sleeping
```

# 7. super()

## Definition

`super()` calls the constructor of the parent class.

Imagine:

```text
Animal

↓

Dog
```

The Dog constructor wants to initialize the Animal part first.

---

Example

```javascript
class Animal {

    constructor(name) {

        this.name = name;

    }

}

class Dog extends Animal {

    constructor(name) {

        super(name);

    }

}

const d = new Dog("Rocky");

console.log(d.name);
```

Output

```text
Rocky
```

---

## Why use `super()`?

Without it:

```javascript
class Dog extends Animal {

    constructor(name) {

        this.name = name;

    }

}
```

Error

```text
Must call super constructor before using 'this'
```

JavaScript requires `super()` before accessing `this` in a derived class.

---

# `super()` with Methods

```javascript
class Animal {

    speak() {

        console.log("Animal Sound");

    }

}

class Dog extends Animal {

    speak() {

        super.speak();

        console.log("Bark");

    }

}

const d = new Dog();

d.speak();
```

Output

```text
Animal Sound
Bark
```

---

# Complete Example

```javascript
class Person {

    constructor(name) {

        this.name = name;

    }

    introduce() {

        console.log("My name is " + this.name);

    }

}

class Student extends Person {

    constructor(name, grade) {

        super(name);

        this.grade = grade;

    }

    study() {

        console.log(this.name + " is studying.");

    }

}

const s = new Student("Ali", "A");

s.introduce();

s.study();
```

Output

```text
My name is Ali
Ali is studying.
```

# Summary Table

| Concept              | Description                            | Example                          |
| -------------------- | -------------------------------------- | -------------------------------- |
| `class`              | Blueprint for creating objects         | `class Person {}`                |
| Object               | Instance of a class                    | `new Person()`                   |
| `constructor()`      | Initializes object properties          | `constructor(name){...}`         |
| Method               | Function inside a class                | `greet()`                        |
| Array Destructuring  | Extract values by position             | `const [a,b] = arr;`             |
| Object Destructuring | Extract properties by name             | `const {name, age} = obj;`       |
| Class Component      | Older React component style            | `class App extends Component {}` |
| Inheritance          | Child class uses parent features       | `class Dog extends Animal {}`    |
| `extends`            | Creates inheritance                    | `class Child extends Parent {}`  |
| `super()`            | Calls the parent constructor or method | `super(name)` or `super.speak()` |

## Which topics matter most today?

For modern React and JavaScript development, prioritize them in this order:

1. ⭐ Object destructuring
2. ⭐ Array destructuring
3. ⭐ Classes and objects
4. ⭐ Inheritance (`extends` and `super()`)
5. ⭐ Class-based React components (mainly to understand older codebases)
