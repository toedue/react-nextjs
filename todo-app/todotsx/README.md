# What To Do

A simple and clean **Todo List App** built with **React, TypeScript, CSS, and Local Storage**.

## Screenshot

![What To Do App](./screenshots/todo-app.png)

## Features

* ➕ Add new tasks
* ✏️ Edit tasks
* 🗑️ Delete tasks
* 💾 Save todos using Local Storage
* ⚡ Built with React and TypeScript

## Technologies

* React
* TypeScript
* CSS
* Local Storage
* React Icons
