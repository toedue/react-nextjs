# Contact Form (React + TypeScript + react-hook-form)

A simple, validated contact form built with React, TypeScript, and the `react-hook-form` library.

## Features

- Name, Email, and Message fields
- Client-side validation (required fields + email format check)
- Inline error messages
- Submission success message
- Form automatically resets after a successful submission
- Responsive layout

## Technologies Used

- React
- TypeScript
- CSS
- `react-hook-form`
